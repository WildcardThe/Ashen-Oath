ASHEN OATH — ARTIFACT IMAGE PROMPTS
====================================

How to use
----------
- Every prompt below is complete: copy one line after "Prompt:" and paste it into the image generator.
- All prompts share the same render style (the last sentence of each prompt), so the set looks
  consistent in the game's artifact slots, inventory and map markers.
- Generate each at 1:1 (square). A plain mid-grey background is requested so I can cut the item out
  cleanly, the same way as the structures.
- "Slot" is where it is worn in our game: Head, Neck, Armour, Cloak, Weapon, Shield, Boots, Ring, Trinket.
- "Rarity" follows our tiers: Treasure (common), Minor, Major, Relic (unique, very rare).
- "Effect" uses the stats the game already has (Attack, Defence, Power, Knowledge, morale, luck,
  movement, sight, mana, spell damage, ranged damage, daily income). Effects marked [NEW] need a
  small new rule; I can add those when we put the artifacts in.
- HoMM3 inspiration is noted in brackets so the role of each item is clear.
- Names avoid trademarked terms; the look is grimdark gothic sci-fi in the spirit of the factions asked for.

Shared style sentence (already included at the end of every prompt):
"Single isolated object centred, three-quarter view, painterly realistic grimdark gothic sci-fi game artifact icon, dramatic rim light, worn and battle-scarred materials, plain flat mid-grey background, no text, no frame, no hands, no people, square 1:1."
