HOW THESE ARE USED
The game cuts each strip into five parts along its length: top tower, upper wall, gate, lower wall, bottom tower. Each part
takes its own state in battle, so an intact tower can sit next to a destroyed wall. That only works if the three versions
line up exactly, part for part:
 - Make INTACT first. Then make DAMAGED and DESTROYED by EDITING the intact picture (image-to-image / 'edit image' /
   'vary region'), not as new pictures. Keep the same size.
 - Check that the gate and both towers are at the same height in all three, and that the moat and wall line stay in
   the same place.
 - If one state comes out shifted, send it anyway; I can line up small shifts.
The keep (the big tower inside the city) stays a separate picture; we already have those.
